## 2024-05-27 - [Standardized Navigation and Accessibility Labels]
**Learning:** Avoid using literal symbols (e.g., '<', '>') for navigation buttons; instead, use descriptive localized text labels and tooltips with keyboard shortcut hints to improve accessibility and clarity for all users.
**Action:** Use standardized i18n keys for navigation (previous, next, collapse, expand) and wrap disabled buttons in <span> within Tooltips to ensure they remain accessible and provide feedback.
